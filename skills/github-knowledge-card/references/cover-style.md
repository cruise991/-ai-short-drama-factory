# Cover Style Reference (小红书爆款知识图谱设计规范)

> **版本**：v2.0 (案例级爆款重构版)  
> **设计基准**：严格遵循用户 5 大爆款案例（AI知识库搭建路线图、JEV Agent系统拓扑、企业AI落地闭环、PPT工具决策树、AI工作流主干流水线）

---

## 一、爆款视觉七大核心定律（Mandatory Rules）

1. **双行视觉核弹标题（Hero Typography）**：
   - 字号：`78px~92px`，字重 `900+`（Heavy/Black），字符紧凑 `letter-spacing: -2px`，行高 `1.08~1.12`；
   - 撞色法则：第一行纯白超大粗体，第二行鲜金高光（`#facc15`），形成极端强烈的反差；
   - **右上角手写体注记（必带）**：倾斜手写字体（如*“从业务问题出发 让AI真正创造价值 ⤴”*、*“从手动搬运到全自动生产 ⤴”*），配手绘细线弯曲小箭头；
   - 顶部左上胶囊：`AI WORKFLOW` / `AI Agent 实战指南`。

2. **三大顶级图谱拓扑架构（Topological Paradigms）**：
   - **范式 A（中央纵向流水线 + 左右翼展对比 —— 案例 5 基因）**：
     - 中央：纵向贯穿的彩色圆角药丸流水线（1~6 节点），步骤间以发光向下箭头穿透连通；
     - 左翼：核心原则框（如 `TOOL ≠ WORKFLOW`）+ 5 项价值勾选清单；
     - 右翼：4 大高危避坑指南 / 5 个关键思考，弧形虚线箭头回指中央节点。
   - **范式 B（中枢立方体 + 左右输入输出发散 —— 案例 1 基因）**：
     - 中央：发光的 3D/2.5D 科技核心立方体（如 `AI Context`），上方输入资料，下方持续迭代；
     - 左侧：输入数据源胶囊堆栈；右侧：输出落地场景胶囊堆栈；
     - 双向发光曲线连接。
   - **范式 C（决策树分叉与环形闭环 —— 案例 2 & 案例 4 基因）**：
     - 条件分叉（“是/否”分支引导至具体工具/方案卡片）；
     - 环形协作圈（中央调度器，外围 5 个 Agent 环形互连）；
     - 横向六步时间线步进（1 Run ➔ 2 Capture ➔ 3 Classify ➔ 4 Patch ➔ 5 Retest ➔ 6 Merge）。

3. **微质感与空间 100% 充盈（Zero Dead-zone）**：
   - 背景：深黑微蓝渐变（`#04060e` 到 `#080c20`），附带 `38px` 极细暗格科技网格；
   - 外框：四周必须有发光科技细边框（1.5px cyan/purple glow）；
   - 空间利用：严禁出现任何超过 100px 的黑色空白死区，元素通过 `flex` 或 `grid` 均匀支撑整个 1080×1440 画幅。

4. **底部压轴金句卡片（Bottom Anchor）**：
   - 必须配置带有发光灯泡 💡 或双引号 ❝ 的思考金句卡片；
   - 提取颠覆性认知（如：*“AI能力的终点不是会用多少工具，而是能不能把工作重新设计成高稳定性的系统”*）；
   - 底部签名栏：标明作者专栏或品牌认证。

## 三、代码工程与渲染标准

1. **渲染分辨率**：强制使用 `1080x1440`（小红书 3:4 黄金画幅）；
2. **文本抗乱码**：一律由无头 Chrome（Google Chrome Headless）执行 HTML5 矢量光栅化；
3. **压缩后处理**：通过 Python PIL 自动转为 88% 质量优化 JPEG，体积严格压制在 `200KB ~ 300KB`，兼顾像素级锐利与 IPC 零超时。
