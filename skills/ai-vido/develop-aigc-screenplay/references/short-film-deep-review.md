# 十五分钟以内短片核心开发

本参考把专业故事开发压缩成一个连续过程。内部探索宽，向用户展示窄；使用硬门，不使用固定节拍、固定候选数、固定序列数或固定字数证明质量。

## 0. 先成片，再集成验收

读取规则和素材后的第一份内部创作文字必须是一段“首画面—失衡—反制升级—终局决定—明确余波”的连续粗骨架。此时允许用“已建立的第二路径”“对手针对性封锁”等功能占位维持因果贯通；随后选择最可运行母体，只补实会造成阻断的机制，并在最终交付前清除占位。四项硬测试和三项电影压力证明针对这条已存在的骨架同步完成，质量门作用于交付前，不作用于开始写作。不要在大纲落笔前分别制作发动机证明、对手证明、高潮证明和场面证明，也不要因一项脆弱而重新搜索全部方向。

专业、科技和工程机制只需证明关键限制、人物行动与可见后果在故事层能够成立。没有必要资料时采用保守假设并标记非阻断风险，不追求唯一工程解，不得让工程推演吞掉完整大纲。用户要求直接交付时，先保证本轮有一套从开场到结尾可阅读的完整故事，再处理不改变母体的措辞和局部优化。

## 1. 创作北极星与输入权重

只记录会改变路线的信息：

- 作品形态、时长、平台和制作方式；
- 观众最主要的情绪变化、类型快感和离场余味；
- 作者真正想追问的价值问题；
- 必须保留的故事事实、关系和视听承诺；
- 明确厌恶的套路、误读和禁区；
- 可自由探索范围；
- 每项输入属于命题、发动机、人物关系、世界规则、场面承诺还是视觉资产。

不要求用户预先回答完整人物弧、结局或结构术语。信息足够便工作，只问会改变电影身份的一个最小问题。

保护创作重力：低层元素默认只改变局部呈现。若视觉或世界设定要升级为发动机，必须证明它会改变人物选择、对手计划、高潮代价与结尾，并检查占用的解释和银幕时间。

## 2. 内部宽搜，外部窄交付

先概括素材最容易生成的默认电影，标记观众能提前预测的任务、救场、中段、高潮和结尾。保留类型承诺，重造发生原因、不可逆后果和最终意义。

从下列根轴进行正向和反向搜索，不必每项都生成候选：

- 换主角或感知中心后，谁承受的矛盾最尖锐；
- 任务若不是摧毁、营救、运送或守住，还能是什么；
- 没有牺牲、爆种、隐藏血统或中央弱点，终局怎样成立；
- 对手最聪明的胜利方案是什么；
- 主角坚持旧策略时，最坏但合理的后果是什么；
- 局部成功怎样制造更大代价；
- 结尾怎样改变开场的意义；
- 哪个地点规则能迫使人物作出只属于本片的选择；
- 哪种关系、权力或信任变化能直接改变胜负方法。

探索只写根假设和短因果链，不为废案扩写完整大纲。出现明显母体且新增方向只剩美术、秘密、设施或牺牲对象换皮时停止。通常只向用户提交一个成熟推荐；只有两个方向均成熟、代表两部电影且北极星无法裁决时，才呈现第二个。

不得把多个候选的设定、反转、高潮和结尾拼成元素合集。吸收局部场面后必须重新验证母体因果。

## 3. 单一因果发动机

成熟推荐必须连续回答：

```text
特定主角与当前生存策略
→ 针对这个人的失衡事件
→ 主角用旧策略解决
→ 对手或压力根据该策略主动反制
→ 每次升级改变资源、关系、空间或价值压力
→ 中段不可逆变化
→ 旧策略彻底失败或被重新评价
→ 终局中不能兼得的选择
→ 具体获胜／失败行动
→ 外部、人物、关系和观众理解的新状态
```

任一箭头只能靠“然后、突然出现、主角终于明白”连接时，不得进入 Skill 2。

初次答出这条因果链后立即把它写成连续故事骨架。后续发现问题只回修造成阻断的箭头，不把整条链重新当作候选搜索题。

根据作品选择任务驱动、关系驱动、观察累积、诗性实验或混合结构。非任务作品改用观看任务、重复差异、形式压力和不可逆终态，不得补造反派、倒计时或传统高潮。

### 人物与关系

把人物写成压力下的决策系统：他保护什么、现在要什么、旧方法为什么曾有效、短期收益与长期代价、最怕支付什么、在权力与依赖面前怎样行动，以及终局中作出什么开场时不会作出的决定。不要用悲惨履历或人物弧标签代替行为。

采用双主角时，让两人各有目标和可见能力，各掌握一半答案，因利益、历史、方法或价值不能立即合作，各自造成不可逆变化，并由关系或权力变化创造终局方法。删除一人后任务、最低谷和终局无需重写，便不是真正双主角。

救场前让被救者拥有有效计划，让对手有针对性地破解，让救援来自此前决定。救场既解除眼前死亡，又改变任务、关系、信息或对手判断；不得只证明救援者强大。

### 战略对手或持续压力

AI、制度、组织或人物型对手必须拥有：具体胜利状态、在主角不行动时也会推进的计划、判断模型、信息边界、主动试探、现实约束、对人物策略的反制、接近成功的路径，以及持续合理却最终形成盲点的逻辑。

用以下闭环让智能可见：

```text
人物行动 → 对手获得证据 → 更新判断 → 针对反制 → 人物被迫改变策略
```

广播、人格和造型不能代替策略。把 AI 换成普通怪物后主要因果仍不变，必须重构。没有战略主体时，让关系反作用、环境、时间或形式规则持续产生可感知后果，不要为了过门而人格化压力。

## 4. 反通用化与高潮三重对齐

母体必须通过四个硬测试：

1. **占位符测试**：去掉专名、美术和时代后，关键选择是否仍可无损套入同类电影；
2. **对手自主测试**：没有主角时，对手或压力是否仍把世界推向具体结果；
3. **高潮归因测试**：谁的哪个决定真正造成胜负或不可逆终态；
4. **主题—机制测试**：情节实际奖励的行为是否与作品追问一致。

传统人物／类型叙事的高潮至少完成三重对齐：

- 外部行动解决、失败或重新定义眼前现实问题；
- 人物采用了与开场不同或最终被证明的策略；
- 获胜／失败方式兑现价值竞争，而不是台词宣布主题。

先决定，再让动作成为决定的物理释放。禁止临时能力、新规则、随机援军、对手突然变笨、更大火力自动胜利和惯性牺牲。代价应从人物与发动机生长，可以是放弃原胜利条件、共享权力、承受身份风险或摧毁赖以生存的旧秩序。

开放的是未来意义，不是眼前事实。明确本次结果、生死、代价和关系状态，只保留一个主要未来问题。

## 5. 三项电影压力证明

三项证明用于检验整部电影能否生场、升级和收束，不作为三段孤立高光，也不必把内部表格展示给用户。

### 开场合同

按平台和片长检查首画面及开场阶段分别提供什么视觉、人物、声音与叙事理由。短视频平台可检查首画面、约3秒、15秒、30秒与60秒；其他平台按体量调整，不机械套秒数。

开场必须让观众感到该跟谁、当下发生什么、人物面临哪个选择，并承诺全片真正会兑现的体验。造型展示应与当前行动连接，不拍与故事无关的广告。

### 连续压力场

内部推演一段约90—180秒的连续核心场；极短片、慢电影或实验作品按自身节奏调整，不把时长当公式。该场必须同时证明：

- 人物当前目标和可判定成功条件；
- 人物、威胁、出口、资源的空间关系；
- 计划如何先奏效；
- 对手或压力如何针对性改变规则；
- 人物如何换策略并作出可见决定；
- 表演行为、环境和声音如何参与冲突；
- 场尾产生什么不可逆结果，并逼出下一步。

在内部短暂比较不同进入方式、地点行动或物理行为，选择最能同时承担观赏、人物和因果的一种。不要写镜头、焦段和运镜。

### 高潮因果图

不用正式对白，写清：

```text
外部危机
→ 人物惯用策略为何失效
→ 对手如何逼迫不能兼得的选择
→ 关系、信息与已付代价怎样改变可行方案
→ 人物最终选择
→ 选择如何成为物理行动
→ 对手的约束或盲点怎样被击中
→ 结果、代价和余波
```

若高潮图必须解释新系统、新权限或新能力，返回发动机层，不用台词补洞。

## 6. 完整大纲与银幕时长

从终局反向列出必要条件，再从首画面正向运行人物行动、压力反作用、局部结果、策略变化和不可逆后果。相邻发展优先由“因此、但是、与此同时造成”连接；重复同一目标、策略和结果，只是敌人更多或换地点，应合并或改变功能。

分别管理真实事实、人物认知和观众认知。观众可以不知道深层答案，但必须知道当前跟谁、追踪什么、人物为何行动和失败会失去什么。每次揭示必须改变行动、关系、风险、代价或胜利含义。

世界背景只沿以下链条进入：

```text
世界规则／历史 → 当下限制、偏见、资源或机会 → 人物或对手行动 → 可见后果
```

不要默认先写历史蒙太奇、会议或旁白；限制并发专名和规则。

按实际内容估算银幕时间，包括对白与呼吸、动作建立、空间辨认、人物反应、停顿、声音、转场、高潮收缩和余波。序列数量与大纲字数只是软预算，不能作为质量公式。最短合理总和超出目标时，先删除重复功能、无后果解释、无独立作用的地点配角和支线，保护人物决定、对手反制、高潮建立与余波。

完整大纲使用自然、连续、可见可听的文字，从首画面写到末画面。它不是正式剧本，但必须让用户能在脑中看见电影，而不是阅读设定说明或节点列表。

## 7. 自检、根因回修与魅力判断

把大纲当作观众唯一能看到的作品，不用作者解释、旧候选或设计表辩护。先用普通语言复述：人物、当下任务或观看问题、为什么现在、主要压力、任务变化、终局选择、明确结果和唯一开放问题。

再检查：

- 首个有效视觉或叙事钩子何时出现；
- 前四分之一能否说清跟谁、追踪什么和为什么现在；
- 人物是否用选择推动转折；
- 对手是否主动改变局势并逼迫新策略；
- 每次升级是否改变打法、关系、资源、空间或价值压力；
- 地点和世界规则是否不可替换地参与因果；
- 高潮是谁用什么决定造成，胜利方式是否兑现主题；
- 结尾行为是否与开场形成可见差异；
- 能否复述一个完整记忆事件，而不只是美术造型；
- 是否具有超出结构合规性的独特声音和“非拍不可”的感觉。

前九项要求文本证据；最后一项是审美判断，不伪装成机器可客观评分的通过状态。校验器只能证明结构完整，不能证明作品一定好看。

把问题分为阻断、脆弱、成立和保护。阻断是因果断裂、观众无法跟随、高潮作弊、事件未闭合或时长实际不可能；脆弱是基本成立但易俗、误读或节奏偏紧。

存在阻断时合并为一至三个最上游根因，只做一次足够范围的回修并定向复验；不要重新开放全部候选，也不要用几十个局部补丁。相同阻断仍存在时停止：若缺一个会改变电影身份的决定，只问用户一个问题；否则如实报告尚未成立。

独立冷读可增加可信度，但不是普通短片的强制手续。没有独立读者时标记为自检，不得伪称盲测通过。

## 8. 交付与停止

向用户只交付一套成熟完整大纲、自然语言情绪路径、三至五个重要电影场面、本次明确结果、唯一开放问题和极简风险。先展示电影，再解释判断。

用户未批准前标记待审阅。交付后停止，不继续制造候选、冷读或正式剧本。
