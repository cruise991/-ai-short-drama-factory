# 诊断交接合同

```markdown
# 项目｜诊断版本

- 材料与范围：
- 锁定来源：
- 一句结论：

## 问题

### ID｜标题
- 类别／优先级：故事阻断／剧本阻断／台词表演／下游风险／建议
- 位置与证据：
- 反馈症状（如有）：
- 根因与影响：
- 修改目标：
- 可选方向与损失：
- 修改范围：台词／单场／段落／全故事
- 负责 Skill：
- 必须保护：
- 验收方式：

## Protect List
- 设计、证据、承担功能、禁止误伤：

## 路由
- 是否退回故事开发：
- 是否需要剧本修订：
- 是否可进入台词精修：
- 是否需要下游专项测试：
- 真实待决定事项：
- 复验版本与结论：
```

没有问题的层级直接写“无”，不要为填满模板制造问题。普通对话交付使用精简自然语言，不输出空表。
