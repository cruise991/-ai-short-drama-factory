# AI 漫剧与数字人直播系统法律合规与开源审查指引

## 一、开源模型与依赖许可证合规审查

### 1.1 LingCast 核心模型与算法合规
- **许可证类型核验**：在将 LingCast 引入生产镜像前，须严格核查其代码仓库（GitHub）及 HuggingFace 权重仓库的实际 License。
  - 若为 **Apache 2.0 / MIT**：允许免费商用，须在发布物和关于页面中保留原作者版权声明和许可文本。
  - 若为 **CC-BY-NC 4.0 / Research Only**：严禁直接用于商业收费流媒体或带货直播服务。若商业化必须联系原作者获取商业授权，或采用双轨制（社区版采用开源模型，商用版采用自研/商业模型）。
- **衍生品与再分发规范**：针对 LingCast 微调后的权重，必须标注基座模型来源及微调数据集授权范围。

### 1.2 语音与 TTS 引擎商用合规边界
| 语音引擎 | 授权与商用边界 | 生产环境合规要求 |
| :--- | :--- | :--- |
| **Edge-TTS** | 基于微软 Edge 浏览器试听接口，**仅供个人学习/非商业测试** | 严禁在生产商业环境直接使用，仅作开发联调回退项 |
| **Kokoro-82M** | Apache 2.0 开源许可，体积小（82M），支持极速推理 | **推荐生产使用**，允许商用，支持英/中双语 |
| **GPT-SoVITS** | MIT 许可，高质量零样本/少样本声音克隆 | 允许商用，但用于克隆声音时**必须取得原声音所有人明确书面授权** |
| **CosyVoice** | Apache 2.0 许可，阿里开源高质量语音合成 | 允许商用，支持多语言与情感控制 |

## 二、法规监管与深度合成标识要求

依据国家互联网信息办公室等七部门联合发布的《生成式人工智能服务管理暂行办法》及《互联网信息服务深度合成管理规定》第十六条、第十七条：

### 2.1 强制显式标识（水印与字幕）
1. **实时直播画面标识**：
   - 直播流画面左上角或右上角必须常驻醒目的 **“AI数字人生成”** 或 **“虚拟主播正在直播”** 文字标识。
   - 字体大小不得小于画面高度的 3%，半透明度不低于 85%，确保用户清晰可辨。
2. **短剧短视频片头与角标**：
   - 视频开头需保留不少于 2 秒的深度合成声明提示或全局动态水印。

### 2.2 隐式防伪溯源标识（数字水印）
- 渲染导出的 MP4/FLV 流必须在元数据中注入不可篡改的元标签（如 `ai_generator: lingcast-factory-v1`、生成时间戳与系统签名），以满足内容安全可溯源监管要求。

## 三、数字人肖像权与名誉权合规红线

1. **绝对红线**：
   - 严禁使用任何在世真人明星、公众人物、未经书面授权自然人的真实肖像进行数字人建模或换脸。
   - 严禁生成涉及淫秽、暴力、政治敏感、虚假新闻或侵害第三方名誉权的音视频内容。
2. **肖像授权流程**：
   - 若引入真人定制数字人，必须签署《自然人肖像与声音数字孪生授权协议》，明确授权用途（短剧/直播）、授权期限、地域范围以及违约责任。
   - 所有角色必须在系统数据库内绑定 `avatar_licensing_spec` 元数据。
